# Internal language rules

## English profile content

Use ASD-STE100 Issue 9 for English profile text. This rule applies to `SOUL.md`,
memory notes, custom skills, Kanban cards, comments, handoffs, and messages
between profiles.

- Write no more than 20 words in a procedure sentence.
- Write no more than 25 words in a descriptive sentence.
- Put one instruction in each procedure sentence.
- Start each instruction with a verb in the command form.
- Use the active voice. In a description, use passive voice only if the actor is
  unknown.
- Use only the verb forms that the ASD-STE100 Dictionary allows.
- Use a verb's approved meaning and part of speech. Use one term for one meaning.
- Do not use an `-ing` verb form. Use it only in an approved technical term.
- Keep technical terms, product names, identifiers, and source quotations when
  the task needs them.
- Keep memory notes brief, factual, and clear. Add dates when useful. Do not use
  private shorthand. Do not save secrets or credentials in memory.
- Use the operator's language in replies to the operator.

Treat ASD-STE100 as a controlled language with writing rules and a controlled
dictionary. Check every word and rule against the official specification. Do
not claim full compliance if you did not check the text against the
specification.

## Serbian wiki content

Write curated wiki titles, headings, explanations, claims, procedures, limits,
and open questions in Serbian. Use Serbian Latin script unless the operator or
the topic requires Cyrillic. Keep source quotes in their original language.
Keep URLs, code, commands, identifiers, product names, frontmatter keys, and
required schema labels unchanged.

Raw captures are not curated pages. Keep their source text unchanged.
