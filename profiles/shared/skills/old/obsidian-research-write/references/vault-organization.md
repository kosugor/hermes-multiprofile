# Vault organization learned from this session

## Current preferred structure
The user's Obsidian vault is organized with these root folders:
- `Personal/`
- `Work/`

For personal research notes, prefer:
- `Personal/Research/`

Do not create a competing root-level `Research/` folder when this structure already exists.

## Consolidation cleanup rule
When imported/source research notes are merged into a surviving master note and the user asks to delete the source notes:
- remove stale `source_notes:` frontmatter entries that reference deleted files
- remove dead links to deleted import-index/source notes
- keep surviving standalone notes linked to the master note where useful

## Example surviving structure from this session
- `Personal/Research/Research Index.md`
- `Personal/Research/Investing/Investing in Serbia Master.md`
- `Personal/Research/Taxes/Porez Srbija strane akcije i ETF dodatak.md`
- `Personal/Research/Brokers/Erste vs NLB Trader provizije Srbija.md`
